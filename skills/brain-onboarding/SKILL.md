# Guided work-brain setup

Read [SETUP.md](../../SETUP.md) and follow its interview, storage and confirmation
rules. Use the user's language. Ask one question at a time, reuse answers and stop
when there is enough context for a useful first task. Do not infer the user's company,
job or apps from this repository.

Offer either a conversational explanation or analysis of a source they choose.
Agree source and scope before reading external data. No connector is required to start.
Show what you understood before the first save. Create one private `MY_BRAIN.md` by
default; return the document if there is no writable private destination.

Do not store real context in the public template, configure accounts, publish, send
messages or schedule anything through this workflow. Confirmed evidence and provisional
interpretations stay distinct. Finish with a small task based on their actual needs.

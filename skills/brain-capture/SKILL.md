# Keep useful context

Read the selected material and relevant existing context. Keep only what helps future
work: decisions, changed constraints, useful learnings and unresolved questions.
Link deliverables in their project instead of copying them into general memory.

Save explicit, evidenced decisions as confirmed. Interpretations and extracted
observations remain provisional even if saving was authorized. Preserve source dates
and consultation dates separately. Avoid transcripts, contact lists and sensitive data.

Use the active private storage format. For one-file brains, update the relevant
sections of `MY_BRAIN.md`; for folder brains, update the corresponding record. Do not
maintain duplicate context in both. In a public template or without private write
access, return the proposed document rather than saving real work information.

State what was saved and what remains uncertain. Capturing context does not authorize
publishing, pushing, merging or changing business systems.

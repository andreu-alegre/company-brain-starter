# Three reusable workflows

| Workflow | When it helps |
|---|---|
| [brain-onboarding](brain-onboarding/SKILL.md) | Start or resume the guided setup |
| [meeting-brief](meeting-brief/SKILL.md) | Prepare one meeting from chosen evidence |
| [brain-capture](brain-capture/SKILL.md) | Keep useful context after a piece of work |

Instructions live here. `.claude/skills/` and `.agents/skills/` contain relative links
to the same folders, not independent copies. If a download loses those links, ask
the assistant to read the `SKILL.md` directly. No global skill installation is required.

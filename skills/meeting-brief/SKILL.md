# Prepare a meeting

Identify the meeting, the user's objective and the selected evidence. Read relevant
private context only if available and in scope. Ask a focused question if an essential
detail is missing; otherwise proceed and show gaps. A calendar invitation does not
prove attendance, and an old snapshot does not prove current status.

Return a brief in the user's language: objective, relevant facts with sources and
dates, previous commitments, open questions and a proposed outcome. Adapt depth to
their role and the meeting. Do not invent people, prices, capabilities or deadlines.

No events, CRM notes, app drafts or messages are created by preparing the brief.
Save privately only if requested. Fictional examples never become real work context.

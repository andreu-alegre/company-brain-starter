# Small templates

- [MY_BRAIN.md](MY_BRAIN.md): the default first output of the guided setup.
- [Project](project.md): use when a project needs its own file.
- [Folder structure](folder-brain/README.md): optional structure for a larger brain.

The assistant fills these from the user's answers and selected sources. They are
not forms the user must complete. Store completed versions privately. A single
brain document can later become an index into the folder structure in [SETUP.md](../SETUP.md).
